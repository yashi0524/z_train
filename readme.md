# 通風管逃脫 (Escape from Z Train)

> 貓咪逃出殭屍列車的瀏覽器遊戲  
> 純前端 · 無需安裝 · 支援電腦與手機

🎮 **Play**: https://yashi0524.github.io/z_train/

---

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 標題/選擇畫面（GitHub Pages 入口） |
| `game.html` | 遊戲主程式（由 index.html 跳轉） |
| `assets_v2.4.js` | 所有角色/物件貼圖（Canvas 2D 手繪） |

---

## 遊戲說明

- 用 **WASD**（或虛擬搖桿）移動貓咪
- 找到地圖上的 🔑 **鑰匙**，再抵達 **EXIT** 出口即過關
- 殭屍每回合從火車衝出，越來越多
- **F 鍵**（或 🚪 按鈕）：躲入附近衣櫃，最多 5 秒
- **空白鍵**（或 ⬆️ 按鈕）：跳躍，可閃過殭屍
- 撿到 🔫 **手槍**：1 發子彈，可擊退殭屍

### 解析度選擇

| 模式 | 尺寸 | 適合 |
|---|---|---|
| A | 800 × 480 | 電腦、iPad 橫向 |
| B | 400 × 640 | iPhone、iPad 直立 |
